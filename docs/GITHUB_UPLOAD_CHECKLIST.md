# GitHub Upload Checklist

Upload these files/folders:

```text
README.md
requirements.txt
.gitignore
notebooks/
scripts/
docs/
results/
```

Do not upload:

```text
archive*.zip
dataset folders
Google Drive output folders
trained models/checkpoints
.pt / .pth / .h5 / .ckpt files
.ipynb_checkpoints
__pycache__
```

Suggested repository name:

```text
lung-cancer-transfer-learning-ensemble
```

Suggested GitHub description:

```text
Lung cancer CT image classification using transfer learning, 5-fold cross-validation, and ensemble learning.
```

Suggested first commit message:

```text
Initial commit: lung cancer ensemble classification project
```
